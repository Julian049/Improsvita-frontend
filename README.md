# Improsvita Frontend

Frontend del proyecto Improsvita

## Estructura

```text
src/
├── api/
├── components/
│   ├── layout/
│   └── ui/
├── context/
├── features/
│   ├── auth/
│   ├── contacts/
│   ├── plantings/
│   ├── reservations/
│   ├── sales/
│   ├── seedlings/
│   └── seeds/
├── hooks/
├── router/
└── utils/
```


## Ejecución

Instalar dependencias:

```bash
npm install
```

Ejecutar el proyecto:

```bash
npm run dev
```
